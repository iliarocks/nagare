# Nagare — 流

A simple task manager for iPhone and Mac.

- See today’s tasks and plan ahead with Upcoming.
- Organize tasks into projects and highlight prioritized projects.
- Add notes, times, and repeating schedules.
- Keep your data on your device, with optional iCloud sync.

Connect an agent through MCP: [https://mcp.nagare.page](https://mcp.nagare.page)
